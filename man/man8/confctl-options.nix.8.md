# confctl-options.nix(8)

## NAME
confctl-options.nix - confctl configuration documentation

## SOURCE
Generated by the Cargo `generate-reference` example, confctl 3.0.0.

Input: an explicit JSON array exported by this repository's `#moduleOptions`.
Defaults and examples retain their exported JSON or Nix-expression form.

## CONFCTL SETTINGS

Configure these options in `configs/confctl.nix`.

### ` confctl.buildGenerations.max `

The maximum number of build generations to be kept.

This is the default value, which can be overriden per host.


Type:

```text
signed integer
```

Default: Nix expression

```nix
30
```

Example: not exported

Declarations:

```text
<confctl/nix/modules/confctl/generations.nix>
```

`confctl.buildGenerations.maxAge` seconds. Old generations
